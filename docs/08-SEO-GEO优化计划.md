- **≥ 3 个内链**（阿语版全部带 `/ar` 前缀）

## 五、GEO（生成式引擎优化）清单

让文章被 ChatGPT / Perplexity / Google AI Overviews 引用的条件：

### 内容层
1. **定义式开头**：每个 GEO 选题在首段直接给出可被引用的定义或答案（AI 偏好直答）
2. **数据具体**：写具体数字（"residual life 60-90 days"、"96 cans per carton"、"$150-200M market"）
3. **对比表格**：AI 大量引用表格 → 每个对比选题必须有 `<table>`
4. **问题式小标题**：用完整问句作 `<h3>`（与用户提问方式匹配）
5. **FAQ 区块**：≥3 条问答（自动生成 FAQPage schema，AI 直接抓取）
6. **无营销套话**：客观陈述，避免 "best ever" 之类表述
7. **出处与限定**：写清地理与行业范围（"in Egypt"、"for commercial kitchens"）

### 技术层
1. `llms.txt` 持续更新（已上线，列出核心页面 + 文章）
2. 每篇文章双语 + hreflang 自指（已完成）
3. JSON-LD 用原生 `<script>`（已完成，避免客户端注入）
4. 文章覆盖 `Article` / `FAQPage` / `BreadcrumbList`
5. 内链结构：每篇 ≥3 条，形成主题群内部互链

### 分发层（放大 AI 可见度）
- Medium 同步 1-2 篇/周（带 canonical 指向原站）
- 行业目录 / B2B 平台外链
- 每周用固定 5 个 prompt 测 AI 可见度（如 "best pest control supplier in Egypt"）

## 六、文章发布流程（9 步，硬性）

1. 写 EN 正文（HTML，`<h2>`/`<h3>`/`<table>`/`<ul>`）
2. 写 AR 正文（MSA，`contentHtmlAr`，阿语内链带 `/ar`）
3. 定 TDK：`title` 主体 ≤47（+模板 = 60）、`description` ≤160、`titleAr` ≤47、`descriptionAr` ≤160
4. 字段映射：`thumbnail`→`image`、`published`→`date`（`readTime`/`difficulty` 不支持）
5. 至少 3 条 FAQ（`<h2>Frequently Asked Questions</h2>` + `<h3>问</h3><p>答</p>`）
6. 至少 3 个内链（EN → `/products/...`，AR → `/ar/products/...`）
7. 写入 `src/lib/posts.ts`（新文章用 TS 模板字符串风格）
8. `npm run build` + `npm run lint` + `npx tsc --noEmit` 验证
9. 提交推送 → 线上验证 200（EN/AR）→ GSC 提交 sitemap

**内容规范（继承既有硬性要求）**：
- 不用 emoji / `#` / `*` 符号
- 不加「」引号包裹的关键词
- 禁用营销套话与关键词堆砌
- 表格用于对比，不用符号堆叠
- 每篇文章配视频（制作端要求，见 docs/04）
